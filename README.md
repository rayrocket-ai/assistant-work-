# Dailies — Personal Video Tracker

A single-file web app (`index.html`) for tracking videos from shoot to post:

- **Pipeline board** — To edit → Editing → To post → Posted, with quick-add,
  search, notes, and per-platform post links.
- **Analyze view** — log view/like/comment/share snapshots per video and
  platform, then see totals, engagement rate, views-over-time trends, and a
  per-platform comparison.
- Data is stored in the browser (localStorage), with JSON export/import for
  backup. No server, no accounts — open `index.html` in any browser.
